# Example deck: Attention Is All You Need

This branch hosts an example HTML deck made with the
[paper-presentation-slides skill](https://github.com/MicDZ/paper-presentation-slides-skill)
for Vaswani et al., "Attention Is All You Need", arXiv:1706.03762v7.

- Slides: `index.html` (arrow keys to navigate, `o` for overview; hover a formula symbol to see its meaning)
- PDF export: `attention-is-all-you-need.pdf`
- Provenance and formula audit: `SOURCES.md`

Figures and tables are reproduced from the paper under its grant for scholarly
use with attribution; rights remain with the authors. The presenter name is a placeholder.
The theme is the MIT-licensed [MBZUAI Beamer Theme](https://github.com/MicDZ/MBZUAI_Beamer_Theme).
